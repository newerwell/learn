### D28 · CSS 变量与设计 token

**动手**：定义
```css
:root { --space-1: 4px; --space-2: 8px; --space-3: 16px;
        --radius: 10px; --fg: #e6e9ef; --bg: #0f1115; --accent: #6ea8fe; }
```
全站替换硬编码值；再用 `[data-theme="dark"]` 覆盖变量实现明暗切换。

**伪代码思路**：
```text
先定义基础 token（颜色、间距、圆角）
再定义组件使用的语义 token（页面背景、卡片背景、正文颜色）

默认主题：
  页面背景 = 浅色基础色
  卡片背景 = 白色
  正文颜色 = 深色基础色

当根元素带有 data-theme="dark"：
  页面背景 = 深色基础色
  卡片背景 = 深灰色
  正文颜色 = 浅色基础色

每个组件只读取语义 token 和间距 token
修改某个 token 后，所有使用它的组件一起更新
切换主题时只替换语义 token 的值，不逐个修改组件样式
```

**判据**
- 改 `--space-3` 一个值，全站间距同步变化
- 切换主题只改变量、不改任何组件样式
- 能说出为什么要分"基础变量"和"语义变量"（`--color-bg` vs `--gray-900`）

## 本阶段常见坑

| 坑 | 表现 | 解法 |
|---|---|---|
| 只看不写 | 教程看完仍然写不出页面 | 每看 30 分钟必须写 60 分钟代码 |
| 硬编码尺寸 | 换个屏就错位 | 用 `rem`/`%`/`fr`/`clamp`，少用固定高度 |
| `innerHTML` 拼字符串 | 遇到特殊字符/XSS 就崩 | `createElement` + `textContent` |
| `useEffect` 之前就依赖状态 | （W9 才会遇到）先记住：状态是渲染出来的 | 这里只要求 DOM 操作直接做 |
| 类型报错就 `as any` | 类型系统失效 | 先读懂报错，再决定用守卫还是改写 |
| 跳过 D21/D22 回炉 | D8–D10 永远停留在"好像懂了" | 这两天的实验必须做完，不能跳 |
