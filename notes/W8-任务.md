### D51 · JS 复盘三问

**目标**：把三个永远不会过时的问题用代码讲清楚。

**动手**：各写一个可运行文件，放在 `projects\task-board\js-review\`：
```js
// 1. 事件循环：为什么 0ms 的定时器排在 Promise 之后？
setTimeout(() => console.log('timeout'), 0);
Promise.resolve().then(() => console.log('promise'));
console.log('sync');
// 输出顺序：？

// 2. 闭包：什么时候变量被回收？
function makeCounter() { let n = 0; return () => ++n; }
const c = makeCounter(); c(); c();
// n 为什么没被回收？如果 c 被置 null 呢？

// 3. 箭头函数：为什么不能当构造函数？
// new (() => {}) 会抛什么错？
```

**判据**
- 能画出"调用栈 → 微任务队列 → 宏任务队列"一轮的顺序
- 能解释闭包让变量活下来的机制（作用域链 + 引用未被回收），而不是"函数记住了值"
- 能说出箭头函数没有 `this`/`arguments`/`prototype`，所以不能 `new`

### D52 · Lighthouse 优化

**目标**：学会用工具量化"页面变好了"。

**动手**
1. 打开 D29 上线的静态站（或本地 `npx serve`）
2. Chrome DevTools → Lighthouse → 勾 Performance / Accessibility / Best Practices / SEO，移动端模式跑一次
3. 记录四项分数
4. 修 3 个问题：图片尺寸/格式、`alt`、颜色对比度、`<html lang>`、meta description 任选三个
5. 再跑一次，记录新分数

**判据**
- 至少两项各提升 10 分以上（把两次分数截图或数字写进笔记）
- 能说出每个问题"为什么影响分数"
- 理解 LCP / CLS / TBT 各指什么（各一句话即可）

### D54 · 项目 1 数据模型

**目标**：让每个用户故事都能落到表结构上。

**动手**：填 `projects/task-board/docs/02-数据模型.md`：

- 主键/外键/索引分别是谁、为什么

### D55 · 项目 1 接口草案

**目标**：让前端不用猜后端。

**动手**：填 `projects/task-board/docs/03-接口设计.md`：
- 8–12 个接口：方法、路径、请求体、成功响应、错误码
- 统一约定：分页参数、错误格式、鉴权方式、时间格式
- 每个接口标注"对应哪条用户故事"

**判据**
- 路径是资源型的（`/tasks`、`/tasks/:id`），没有 `/getTasks` 这种
- 状态码用得对：创建 201、未登录 401、无权限 403、不存在 404、校验失败 422
- 分页/错误格式在所有接口里一致
