    D18：盒模型实验

    两个盒子的 width 都是 200px，比较它们的实际宽度和内容区域。

    A：content-box
    B：border-box
    • A：内容宽 200px，边框盒宽 250px，加上左右 margin 共 270px。
    • B：内容宽 150px，边框盒宽 200px，加上左右 margin 共 220px。

    在 DevTools 的 Elements 中分别选中两个盒子，查看 Computed 里的盒模型图。

    Console 中可用下面这行读取 A 的边框盒宽度；把 .a 改成 .b 可测量 B。结果不包含 margin。

    document.querySelector('.a').getBoundingClientRect().width

    D19：Flex 布局实验

    父容器设置 display: flex，三个直接子元素参与排列。

    1
    2
    3
    1. 对齐：修改父容器的 justify-content 和 align-items，观察居中、靠右和两端对齐。
    2. 方向与间距：把 flex-direction 改成 column，观察主轴变化；修改 gap，观察间距。
    3. 空间分配：恢复 row，取消子元素中 flex: 1 的注释，观察三个盒子的宽度变化。
    4. 换行：重新注释 flex: 1，将父容器设置为 flex-wrap: wrap、width: 180px、height: auto。

    记住：justify-content 管主轴，align-items 管交叉轴；row 和 column 会改变两条轴的方向。
