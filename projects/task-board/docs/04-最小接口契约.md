# D57 · 最小接口契约

这份契约对应仓库中的 mock 服务 labs/mock-tasks-api/server.mjs，供阶段 2 的 React 前端练习使用。它描述当前服务的真实行为，不包含登录、权限或生产级保证。

## 基本约定

| 项目 | 约定 |
|---|---|
| 本地 Base URL | http://127.0.0.1:3200 |
| 请求体 | 创建和更新请求使用 JSON，并发送 Content-Type: application/json |
| CORS | 本地练习服务允许跨源请求；仅用于开发 |
| 鉴权 | 无 |
| 日期 | dueAt 和 createdAt 使用 ISO 8601 字符串；dueAt 可以为 null |
| 任务对象 | id、title、done、dueAt、tags、createdAt |
| 错误响应 | { "code": "...", "message": "...", "details": {} } |

示例任务：

~~~json
{
  "id": "t_1",
  "title": "任务 01",
  "done": true,
  "dueAt": "2026-11-15T08:00:00.000Z",
  "tags": ["life", "urgent"],
  "createdAt": "2026-11-15T08:00:00.000Z"
}
~~~

实际日期由服务启动时间生成。

## 接口清单

| 用途 | 方法 | 路径 | 请求 | 成功响应 |
|---|---|---|---|---|
| 任务列表 | GET | /api/tasks?page=1&pageSize=10&q=&done= | 查询参数均可省略 | 200，分页对象 |
| 创建任务 | POST | /api/tasks | { "title": "写周报", "dueAt": null, "tags": ["work"] } | 201，任务对象；带 Location 响应头 |
| 更新任务 | PATCH | /api/tasks/:id | 部分任务字段，例如 { "done": true } | 200，更新后的任务对象 |
| 删除任务 | DELETE | /api/tasks/:id | 无 | 204，无响应体 |
| 演示错误 | GET | /api/error?status=500 | status 可省略，默认 500 | 返回指定错误码和错误对象 |

### 任务列表

page 从 1 开始，默认为 1；pageSize 默认为 10，并限制在 1–100。q 按标题不区分大小写搜索。done=true 只返回已完成任务，done=false 只返回未完成任务；省略 done 或传空值时不按完成状态筛选。

~~~http
GET /api/tasks?page=1&pageSize=10&q=不存在&done=false
~~~

~~~json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 10
}
~~~

### 创建任务

title 必须是非空字符串，最多 200 个字符；保存前会去掉首尾空格。dueAt 和 tags 可省略。

~~~http
POST /api/tasks
Content-Type: application/json
~~~

~~~json
{ "title": "写周报", "dueAt": null, "tags": ["work"] }
~~~

成功返回 201，并在 Location 响应头中给出新任务地址。无效 JSON 返回 400；标题为空或超过 200 个字符返回 422。

### 更新与删除

PATCH 只提交要修改的字段。可更新 title、done、dueAt、tags；标题沿用创建接口的非空及长度检查。任务 ID 不存在时，PATCH 和 DELETE 都返回 404。

~~~http
PATCH /api/tasks/t_1
Content-Type: application/json
~~~

~~~json
{ "done": false }
~~~

DELETE 成功时返回 204，不带 JSON 响应体。重复删除同一个 ID 会返回 404。

### 错误示例

请求 GET /api/error?status=500 会得到 HTTP 500：

~~~json
{
  "code": "DEMO_ERROR",
  "message": "这是我故意返回的 500",
  "details": {}
}
~~~

访问不存在的任务会得到 HTTP 404：

~~~json
{
  "code": "TASK_NOT_FOUND",
  "message": "任务 t_99 不存在",
  "details": {
    "id": "t_99"
  }
}
~~~

## 运行与边界

在仓库根目录启动服务：

~~~powershell
node labs\mock-tasks-api\server.mjs
~~~

服务默认监听 127.0.0.1:3200，每次请求约延迟 300ms。数据仅在内存中，服务重启后恢复种子数据；它没有鉴权、持久化、事务或并发控制。GET /api/error?status=500 用于练习错误态。服务也提供 /api/slow?ms=3000，供后续加载和取消请求练习，本日最小契约不要求前端实现这些状态。
