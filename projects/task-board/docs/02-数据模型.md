## 五、关键取舍（面试会问）

1. **标签怎么存**：关联表 vs 任务表里一个 JSON 数组。你选哪个？代价是什么？
   - 关联表：可筛选、可统计、可复用；写入和查询更复杂
   - JSON 列：简单；但筛选/排序/统计都变难，改结构要迁移数据
2. **时间存 UTC 还是本地**：为什么？
3. **软删除**（`deleted_at`）还是硬删除：什么场景必须软删除？
